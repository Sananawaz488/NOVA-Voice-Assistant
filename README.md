# NOVA Voice Assistant 🎤

NOVA is a personal AI voice assistant built with Python, Streamlit and Groq AI.

## Features

- Voice interaction
- AI conversation
- English and Roman Urdu support
- Google search commands
- YouTube search commands
- Text input
- Voice response support
- Responsive dark interface

## Technologies

- Python
- Streamlit
- Groq API
- JavaScript
- CSS
- Web Speech API

## AI Model

NOVA uses:

openai/gpt-oss-120b

through the Groq API.

## Security

The Groq API key should be stored in Streamlit Secrets.

Never upload the API key to GitHub.
